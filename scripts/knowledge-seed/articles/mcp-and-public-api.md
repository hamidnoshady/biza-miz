می‌توانید به Claude، ChatGPT و دستیارهای مشابه اجازه بدهید «به دادهٔ کسب‌وکارتان دسترسی داشته باشند» — با کنترل دقیق از خود شما.

## این چیست؟

برنامه شما یک سرور MCP و یک API عمومی دارد. دستیار خارجی با یک کلید/مجوز که شما صادر می‌کنید وارد می‌شود و فقط کارهایی را می‌تواند بکند که scope کلید اجازه دهد.

## راه‌اندازی اتصال MCP

1. از اتصال‌های فنی، «اتصال دستیار جدید» را بزنید.
2. نام و محدودهٔ دسترسی را مشخص کنید (مثلاً فقط خواندن گزارش فروش، بدون ثبت سند).
3. کد/لینک اتصال را در دستیار (Claude یا هر کلاینت MCP) وارد کنید و در صفحهٔ رضایت، دسترسی خواسته‌شده را تأیید کنید.
4. هر وقت خواستید قطعش کنید، کلید را باطل می‌کنید — همهٔ نشست‌های آن دستیار هم از کار می‌افتد.

## یک دستیار وصل‌شده چه می‌تواند بکند؟

- گزارش بخواند و تحلیل کند («سه قلم پرفروش هفتهٔ گذشته چی بود؟»)
- بسته به مجوز، کارهای مشخص خودکار کند؛ همهٔ خواندن/نوشتن‌ها رویداد حسابرسی دارد.

## چه چیزهایی عمداً ممنوع است؟

- دسترسی به دادهٔ کسب‌وکار دیگر روی همین سکو (جداسازی کسب‌وکارها سخت است).
- کاری فراتر از scope کلید؛ کلید فقط‌خواندنی هرگز نمی‌تواند چیزی بنویسد.

## نکتهٔ امنیتی

- مجوز را کوچک صادر کنید؛ می‌شود بعداً بزرگ‌ترش کرد.
- لا صفحهٔ رویدادها هر چند وقت یک بار نگاه کنید — هر فعالیت کلید ثبت می‌شود.

برای آشنایی با دستیار داخلی خود برنامه (که رمز نمی‌خواهد)، [دستیار هوشمند](/knowledge/a/ai-assistant) را ببینید.
