«اتصال‌های فنی» محل زندگی چیزهایی است که به کسب‌وکار شما وصل می‌شوند: برنامهٔ دسکتاپ، نرم‌افزار مالی هلو، و کلیدهای برنامه‌نویس.

## برنامهٔ دسکتاپ

برای صندوق روی کامپیوتر فروشگاه (با چاپگر و کشوی پول محلی) برنامهٔ دسکتاپ نصب می‌شود:

1. در این صفحه «کد اتصال دسکتاپ» بسازید.
2. روی کامپیوتر صندوق برنامه را باز کنید و همان کد یک‌بارمصرف را وارد کنید — تمام.
3. کد هر دستگاه جدا صادر می‌شود و اگر دستگاهی گم/فروخته شد، کدش را از همین‌جا «لغو» کنید.

جزئیات چاپگر محلی در [حالت آفلاین و سخت‌افزار](/knowledge/a/offline-hardware).

## هلو (حالت همراه)

اگر حسابداری‌تان هلو است، می‌توانید برنامه را در کنار هلو نگه دارید: فروش‌ها و موجودی به هلو آینه می‌شوند و دفتر مالی اصلی آنجا می‌ماند. قوانین مهم:

- چیزی که مال هلو است (از آنجا آینده شده) را در این برنامه **ویرایش نکنید**؛ تغییر از مبدأ انجام می‌شود تا دفترها از هم جدا نشوند.
- نگاشت سرفصل‌ها و اقلام در همین صفحه/تب هلو انجام می‌شود؛ نگاشت صحیح = تراز درست هر دو طرف.

## کلیدهای API برنامه‌نویس

برای اتصال نرم‌افزارهای خودتان (اتوماسیون، ربات گزارش…):

1. کلید API بسازید و محدودهٔ دسترسی (scope) را دقیق انتخاب کنید — کمترین دسترسیِ لازم قاعده است.
2. «آزمایش اتصال» نشان می‌دهد کلید کار می‌کند یا نه.
3. کلید را مثل رمز نگه دارید و در کد عمومی قرار ندهید؛ لو رفت؟ همان لحظه باطلش کنید و کلید تازه بسازید.

نمونهٔ فراخوانی سالم کلید:

```bash
curl -H "Authorization: Bearer YOUR_API_KEY" https://your-shop.example.com/api/v1/orders
```

## اعلان‌های اتصال

قطعی کلید یا هلو از مسیر [اعلان‌ها](/knowledge/a/notifications) به مدیر هشدار داده می‌شود؛ اگر همگام‌سازی هلو قرمز بود اول به همین صفحه بروید.
