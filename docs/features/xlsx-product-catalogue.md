# Review an Excel product catalogue

Open **Settings → Data Transfer → Product catalogue**, or use **Import from Excel** on the Products or Watch page. Both entry points open the same wizard. The import requires Data Transfer import access and inventory adjustment access for the active branch. Woo review also requires WooCommerce management access to the chosen store.

1. Upload the first worksheet of an XLSX file with headers on row 1. The limit is 2 MiB, 1,000 data rows and 100 columns. Confirm the SKU and name columns and map the remaining fields. Use a stable source name when importing future files from the same supplier. A previous review with the same headers can supply the mapping.
2. Review the row numbers, normalized values and warnings. For each repeated SKU, choose the physical row that represents the item, or leave the group on hold. The source values and all duplicate row numbers are preserved. Select the fixed Omax brand only for an approved Omax source.
3. Review local matches and approve creation or linking. Watch rows create one serialized model per SKU with typed watch specifications and no physical units. Retail families require a parent SKU, a consistent parent title, a named branch attribute axis and distinct option values on at least two sellable child SKUs. A file with ordinary model specifications produces simple products.
4. Choose a Woo store and review the candidates and taxonomy IDs. A REST store is queried directly. On a current connector, request the read-only preview, then refresh after the connector polls. An older connector can expose its existing mirror with a clear verification warning. An ambiguous or incompatible match is held. Existing products are linked without replacing store presentation. Creating a draft requires explicit store confirmation, and creating missing categories or global attribute terms has its own opt-in. Variation drafts use the existing per-store attribute definition mappings.
5. Confirm local application. The wizard processes bounded batches and retains the reconciliation run and its audit history. Reopen the run to continue an interrupted apply. If the catalogue changed, use a fresh preview. Use the downloadable report to reconcile physical worksheet rows, including family members and skipped fields.
6. Confirm each selected store operation after the local item has applied. Refresh delivery status to see queued, processing, review, failed or Woo-confirmed outcomes. For families, the parent ACK creates the child jobs. Each child has its own status. A draft with no reviewed price remains a draft. This import creates metadata-only mappings with automatic price and stock pushes paused.

The file workflow never applies a source price, cost, quantity or serial number, including formulas with cached values. Confirm stock and prices through the usual Accounting flows. Full Offline supports local review and apply. Hybrid uses the cloud-hosted settings workflow for Woo operations.
